  • 3-Surface 구조 — 입주민 앱(iOS/Android), 아파트 관리자 웹(반응형), 내부 관리 시스템(반응형 웹) 3개 클라이언트를 단일 백엔드 API로 연동

  • BI 대시보드 — 관리비/시설/건의 데이터를 시각화한 핵심 관리자 대시보드 (5차 고도화 BI 확장 호환 데이터 모델)
  • PG·SMS 외부 API — 관리비/시설이용료 결제 정산, SMS 인증·알림 발송 안정 연동
  • 5차 고도화 호환 데이터 모델 — 단지별 멀티테넌트 분리, 시계열 적재 구조, 향후 BI 확장을 고려한 정규화/이력 테이블 설계
  • '깔끔하고 댄디한' UI/UX — 아파트아이·노트타운 벤치마크, 직관적 정보 전달과 기능 접근성 우선

제안 포인트

1. 동일 스택·동일 구조의 B2B SaaS 운영 경험

본 프로젝트와 동일한 Flutter(앱) + NestJS(API) + Next.js(웹) 스택으로 멀티테넌트 B2B SaaS(시니어 주간보호 통합 관리 플랫폼)를 6개 플랫폼·140+ API·90개 DB 마이그레이션 규모로 구축한 경험이 있습니다. '다중 시설을 단일 시스템에서 관리'했던 구조를 '다중 단지 관리'로 그대로 이식할 수 있어 학습 비용 없이 1차 안정 기반을 확보합니다.

2. 5차 고도화·BI 확장을 고려한 데이터 모델링

VC 펀드 관리 SaaS(Series B)에서 80+ 데이터 엔티티·179개 마이그레이션·5종 규제 보고 양식을 다루며 "데이터를 차곡차곡 쌓는" 시계열 적재 구조를 설계한 경험이 있습니다. 본 프로젝트에서도 단지·세대·관리비·시설·투표·건의 도메인을 BI 확장에 호환되도록 정규화·이력 테이블·Snapshot 패턴으로 설계합니다.

3. 안전한 결제·인증·외부 API 연동

P2P 크라우드펀딩 플랫폼에서 가상계좌 자동화(Seyfert/PayGate), NICE KYC, 15+ 외부 API 연동을 수행했고, 사내 그룹웨어 SaaS(EZ-Approve)에서 Ppurio SMS·FCM·SMTP 12종 외부 서비스를 통합한 경험이 있습니다. PG·SMS 연동을 안정적으로 처리합니다.

4. 운영 효율성을 높이는 기능 제안

요구사항을 그대로 구현하는 것을 넘어, 관리자 대시보드의 KPI 카드·이상 징후 알림·투표 참여율 트래킹처럼 운영자가 의사결정에 즉시 활용할 수 있는 시각화 패턴을 제안합니다. 시설 이용 데이터는 시계열로 적재하여 향후 수요 예측·요금 정책 수립에 그대로 활용합니다.

5. 단계별 마일스톤·NDA 체결

30일 단위 5개 마일스톤으로 진행 상황을 가시화하며, 입주민 개인정보·관리비 등 민감 데이터 보호를 위해 계약 즉시 NDA 체결 가능합니다. 1차 안정 기반 마련 후 5차 고도화로 자연스럽게 이어질 수 있는 아키텍처를 설계합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

1.1 배경

기존 아파트 관리 서비스(아파트아이 등)는 폐쇄적이고 복잡한 UI/UX로 입주민 활용도가 낮고, 운영 데이터가 단순 기록 차원에 머물러 있습니다. 입주민과 관리 단체를 효율적으로 연결하고, 운영 데이터를 BI로 활용해 의사결정에 직접 반영할 수 있는 표준 플랫폼이 부재합니다.

1.2 목적

  • 관리비·공지·전자투표·건의·시설 예약 등 필수 기능을 단일 B2B SaaS 플랫폼으로 통합

3. 기능 요구사항

3.1 인증 및 권한 관리

  • [필수] 휴대폰 번호 기반 통합 로그인 (입주민·관리자·운영자 공통)
  • [필수] 동/호수 기반 세대 인증 (관리자 승인 워크플로우 포함)
  • [필수] 역할별 RBAC 권한 매트릭스 (CASL 기반, 4종 역할)
  • [필수] 세션·토큰 만료 정책, 보안 로그

3.2 데이터 관리 (ERP/CRM)

  • [필수] 관리비 조회 / 고지서 확인 / 납부 (앱·웹)
  • [필수] 입주민 등록·수정·삭제, 세대별 마스터 관리 (관리자)
  • [필수] 시설(헬스장·독서실 등) 예약 시스템 + 이용 현황 데이터 적재
  • [필수] 시설 정책(이용 시간·요금) 운영 관리

3.3 소통 및 투표

  • [필수] 전자투표 (안건 등록, 투표 진행, 결과 공개, 익명/실명 옵션)
  • [필수] 단지 공지 작성 + 입주민 앱 실시간 푸시 알림(FCM)
  • [필수] 입주민 건의함 (제출·접수·처리 상태)
  • [필수] 하자 보수 접수 (사진 첨부, 처리 단계 추적)

3.4 BI 관리자 대시보드

  • [필수] KPI 카드 (관리비 수납률, 시설 가동률, 투표 참여율, 건의 처리율)
  • [필수] 시계열 차트 (월별 관리비, 시설 이용 추이, 건의 접수 추이)
  • [필수] 카테고리별 분포 (시설별 이용률, 건의 유형별 분포)
  • [필수] 필터·드릴다운 (단지·기간·카테고리)

3.5 결제 (PG 연동)

  • [필수] 관리비 PG 결제 (카드, 가상계좌, 계좌이체)
  • [필수] 시설 이용료 결제 (예약 시 결제, 환불 정책)
  • [필수] 결제 영수증 발급, 결제 내역 조회
